自己接入？只需要两个字段

POST https://jevhub.store/api/v1/decide

服务端请求头：Authorization: Bearer $JEV_API_KEY。请求体不带 model，模型由托管网关选择。

{
  "state": { "message": "Please correct the company name on my receipt." },
  "questions": {
    "wants_refund": {
      "type": "noul",
      "instructions": "Does the customer explicitly request a refund?"
    }
  }
}

模拟响应：answers.wants_refund.noul = 0.02，usage.input_tokens = 180。概率不是执行退款的授权。

// Node.js 20+ 服务端；将参考文件放到同一服务端目录。
import { createJevClient } from './jev-client';

const decide = createJevClient({
  onUsage: ({ input_tokens }) => console.info('jev_usage', { input_tokens })
});
// 在 async 服务端函数中调用，并捕获 JevError。
const result = await decide({
  state: 'Please correct the company name on my receipt.',
  questions: {
    wants_refund: {
      type: 'noul',
      instructions: 'Does the customer explicitly request a refund?'
    }
  }
});
const refundProbability = result.answers.wants_refund.noul;

选对问题类型

类型问题设计读取结果
choice从明确选项中选一个；criteria 是选项对象，建议含 other。answers.问题名.choice
score按2–10个具体等级评估程度，从0开始，可返回小数。answers.问题名.score
noul判断一个条件是否成立，返回“是”的概率，不是程度。answers.问题名.noul

state 放事实，instructions 写完整判断，criteria 定义边界。同一上下文的独立问题可以合并，但额外问题仍消耗 tokens。置信度和阈值需要用业务样本验证。

失败时怎么办

状态处理方式
400 / 403检查请求 / 权限，不重试。
401密钥无效或已撤销，在服务端更换。
402账户余额不足，先充值。
429 / 503指数退避，最多初次+2次重试；尊重 Retry-After。
网络 / 超时 / 其他状态不自动重试；结果可能未知，先核对用量。

每次请求15秒超时。记录 input_tokens 是用量追踪，不代表计费只看输入。不要把原始错误响应、用户隐私或密钥写入日志。
